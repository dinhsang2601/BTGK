## 2. Mục đích của trang
Trang chủ đóng vai trò là "gương mặt đại diện" của nền tảng CultureTrail. Mục đích chính của trang là thu hút, truyền cảm hứng cho người dùng thông qua giao diện trực quan, đồng thời cung cấp công cụ tìm kiếm nhanh chóng để du khách có thể tra cứu các trải nghiệm văn hóa bản địa độc đáo tại 3 miền Việt Nam.

## 3. Các chức năng chính
- **Giao diện Responsive:** Trang web hiển thị tốt và tự động thích ứng layout trên 3 môi trường: Desktop (Máy tính bảng/PC), Tablet (Máy tính bảng) và Mobile (Điện thoại).
- **Render dữ liệu động (JS):** Danh sách "Tinh hoa văn hóa 3 miền" (6 tấm thẻ) không cố định trong HTML mà được JavaScript khởi tạo và vẽ (render) tự động từ mảng dữ liệu (Array of Objects).
- **Tương tác Tìm kiếm (JS):** Người dùng có thể gõ từ khóa (ví dụ: "Hội An", "Sapa", "Gốm") vào thanh tìm kiếm. Hệ thống sẽ lọc và hiển thị ngay lập tức các hành trình phù hợp (không phân biệt chữ hoa/thường) mà không cần tải lại trang.

## 4. Công nghệ sử dụng
- **HTML5:** Xây dựng cấu trúc Semantic (sử dụng `<header>`, `<main>`, `<section>`, `<footer>`).
- **CSS3:** Tạo kiểu giao diện, ứng dụng Flexbox và CSS Grid Layout. Tích hợp Media Queries để xử lý Responsive.
- **Vanilla JavaScript (ES6+):** Xử lý logic, thao tác DOM, bắt sự kiện form submit và xử lý mảng (Array methods: `.forEach()`, `.filter()`).
- **FontAwesome:** Tích hợp thư viện hiển thị icon.
